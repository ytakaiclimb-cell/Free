# POP INSTA — A4 の POP をインスタサイズへ

A4 で作った POP は縦長（1:1.414）で、インスタの枠（1:1 / 4:5 / 9:16）には
そのまま入りません。このアプリは、**切らずに収める**か **枠いっぱいに切り抜く**かを
選んで、1080px の投稿用画像を書き出します。

## 使いかた

1. **写真から** または **PDF から** で POP を読み込む
   （ギャラリーの写真のほか、Word や Canva から書き出した **PDF もそのまま**読めます。
   複数ページの PDF は「前へ / 次へ」でページを選べます）
2. **サイズ** を選ぶ — 1:1（正方形 1080×1080）/ 4:5（縦長 1080×1350）/ 9:16（ストーリー 1080×1920）
3. **合わせかた** を選ぶ
   - **全体を入れる** … POP を切らずに収め、余った場所を背景で埋めます（文字が切れません）
   - **切り抜く** … 枠いっぱいに広げます。見せたい部分を指でドラッグ、ピンチで拡大
4. **背景** を選ぶ — 紙色（POP の紙の色を自動で拾います）/ 白 / 生成り / 黒 / ぼかし
5. **余白** のスライダーで、POP のまわりの余白を調整
6. **保存**（ギャラリーの `Pictures/POP` に入ります）または **Instagram へ**

- プレビューは**ダブルタップで位置リセット**
- **3サイズまとめて保存** で、同じ設定のまま 1:1 / 4:5 / 9:16 を一度に書き出せます
- 他のアプリの共有メニューから、写真や PDF を直接このアプリに送れます

## 仕組み

- 書き出しは常に幅 1080px の JPEG（Instagram の表示解像度に合わせています）
- 縮小は段階的に行うので、POP の細かい文字がつぶれにくくなっています
- 「紙色」は POP の外周 1 列の平均色、「ぼかし」は縮小した POP を引き伸ばしたもの
- 権限は不要です（写真選択と自分が保存した画像しか触りません）

## ブラウザ版（`web/`）

同じ変換を、インストールなしでブラウザの中だけで行います。パソコンと iPhone は
こちらを使ってください。

- 画像も PDF も読めます（PDF は同梱した pdf.js で描画。ページ送りも同じ）
- **動画も同じ枠に変換できます** — 下の「動画」を参照
- 変換はすべて端末の中で完結します。アップロードは一切ありません
- **保存** はダウンロード、**共有 / Instagram へ** は端末の共有シート
  （iPhone は共有シートから Instagram に直接渡せます）
- ドラッグ＆ドロップ、貼り付け（Ctrl/⌘+V）でも読み込めます
- ホーム画面に追加するとアプリのように開けます

```
web/
├── index.html            画面
├── app.js                変換とプレビュー（Android 版と同じ計算式）
├── video.js              動画の再エンコード（WebCodecs）
├── style.css             配色
├── install/              APK の配布ページ（QR コード）
└── vendor/               pdf.js と mp4-muxer（同梱。CDN を使いません）
```

### 動画

手持ちの動画を、写真とまったく同じ操作で 1:1 / 4:5 / 9:16 に合わせて MP4 に
書き出します。余白・背景・位置合わせもそのまま効き、**背景「ぼかし」は映像に
追従**します。音声はそのまま引き継ぎます。

- 書き出しは **H.264 + AAC の MP4**（Instagram が受け付ける形式）。端末が H.264 を
  持たない場合は VP9 になり、その旨を画面に出します
- 端末の中だけで再エンコードします（WebCodecs）。Chrome / Edge / Android Chrome /
  iOS 17 以降の Safari で動きます
- 処理は再生と同じ速度で進みます。30 秒の動画なら 30 秒ほど。**その間は画面を
  消さないでください**（対応端末では自動でスリープを止めます）
- 3 分を超える動画は時間とメモリを食うので、警告を出します
- 動画のときだけ「3サイズまとめて保存」は使えません（1 サイズずつ書き出します）

# M.P.C — Monograph Panel Controller

音楽機材をモチーフにした Android ホームアプリ（ランチャー）です。
アプリアイコンの色や形をすべて捨てて、パッド・ノブ・フェーダーだけで
ホーム画面に統一感を持たせます。

## APK のダウンロード（スマホだけで完結します）

**[最新ビルドをダウンロード](https://github.com/ytakaiclimb-cell/Free/releases/latest/download/mpc.apk)**

このリンクは常に最新ビルドを指します。ブックマークしておけば、更新のたびに
同じリンクから落とせます。

1. 上のリンクをタップして `mpc.apk` をダウンロード
2. 通知からファイルを開いてインストール
3. 初回のみ「提供元不明のアプリ」のインストール許可を求められるので許可
4. ホームアプリに設定するには、**空いている場所を長押し → 編集バーの「ホーム設定」**

固定のデバッグ鍵で署名しているので、2 回目以降は**アンインストールせずに上書き**できます。

## モジュール

| | 操作 |
|---|---|
| **パッド** | タップでアプリ起動。**下にスライド**で裏に割り当てたアプリを起動（黄色いドットが目印）。**通知があるとパッド全体がオレンジに発光**。長押しで割り当て変更 |
| **ノブ** | タップで回転しながらフォルダが開く。中の「＋」でアプリ追加、アプリ長押しで削除 |
| **フェーダー（VOL）** | 上下でシステム音量。タップでミュート切り替え |
| **フェーダー（BRT）** | 上下で画面の明るさ。タップで自動調整（AUTO）切り替え |
| **フェーダー（ランチャー）** | 上に弾く / 下に弾くで別々のアプリを起動。タップで割り当て |
| **カレンダー** | スピーカーの網目状のドットマトリクス。今日がオレンジ |
| **時計** | 時:分＋秒、右に日付と曜日 |
| **メディア** | 再生中の曲名を表示。レベルメーターが動き、タップで再生 / 一時停止 |

## 画面まわり

- **ページ**: 横スワイプで切り替え。各ページに縦書きのタイトル（M.P.C / BACKYARD …）
- **編集モード**: 空いている場所を長押し。モジュールをドラッグしてグリッド上の好きな位置へ。左上の × で削除。ページ追加・初期化も編集バーから
- **ドロワー**: 画面下のバーを上にスワイプで全アプリ一覧（検索付き）
- **折りたたみ対応**: 開いた状態と閉じた状態で**別々のレイアウトを記憶**し、画面幅に応じて自動で切り替わります
- **起動演出**: ホームに戻るたび・ページを切り替えるたびに、フェーダーが所定位置へ走り、ノブが回り、カレンダーが順に点灯します

## 権限について

| 機能 | 必要な許可 | 許可しない場合 |
|---|---|---|
| パッドの通知発光 / メディア表示 | 通知へのアクセス | 光らない・曲名が出ないだけ |
| BRT フェーダー | 設定の変更（WRITE_SETTINGS） | タップすると許可画面が開きます |

どちらも編集バーの「通知」、または BRT フェーダーのタップから許可画面に飛べます。
