# M.P.C — Monograph Panel Controller

音楽機材をモチーフにした Android ホームアプリ（ランチャー）です。
アプリアイコンの色や形をすべて捨てて、パッド・ノブ・フェーダーだけで
ホーム画面に統一感を持たせます。

## APK のダウンロード（スマホだけで完結します）

**[最新ビルドをダウンロード](https://github.com/ytakaiclimb-cell/Free/releases/latest/download/mpc.apk)**

このリンクは常に最新ビルドを指します。ブックマークしておけば、更新のたびに
同じリンクから落とせます。

1. 上のリンクをタップして `mpc.apk` をダウンロード
2. 通知からファイルを開いてインストール
3. 初回のみ「提供元不明のアプリ」のインストール許可を求められるので許可
4. ホームアプリに設定するには、**空いている場所を長押し → 編集バーの「ホーム設定」**

固定のデバッグ鍵で署名しているので、2 回目以降は**アンインストールせずに上書き**できます。

## モジュール

| | 操作 |
|---|---|
| **パッド** | タップでアプリ起動。**下にスライド**で裏に割り当てたアプリを起動（黄色いドットが目印）。**通知があるとパッド全体がオレンジに発光**。長押しで割り当て変更 |
| **ノブ** | タップで回転しながらフォルダが開く。中の「＋」でアプリ追加、アプリ長押しで削除 |
| **フェーダー（VOL）** | 上下でシステム音量。タップでミュート切り替え |
| **フェーダー（BRT）** | 上下で画面の明るさ。タップで自動調整（AUTO）切り替え |
| **フェーダー（ランチャー）** | 上に弾く / 下に弾くで別々のアプリを起動。タップで割り当て |
| **カレンダー** | スピーカーの網目状のドットマトリクス。今日がオレンジ |
| **時計** | 時:分＋秒、右に日付と曜日 |
| **メディア** | 再生中の曲名を表示。レベルメーターが動き、タップで再生 / 一時停止 |

## 画面まわり

- **ページ**: 横スワイプで切り替え。各ページに縦書きのタイトル（M.P.C / BACKYARD …）
- **編集モード**: 空いている場所を長押し。モジュールをドラッグしてグリッド上の好きな位置へ。左上の × で削除。ページ追加・初期化も編集バーから
- **ドロワー**: 画面下のバーを上にスワイプで全アプリ一覧（検索付き）
- **折りたたみ対応**: 開いた状態と閉じた状態で**別々のレイアウトを記憶**し、画面幅に応じて自動で切り替わります
- **起動演出**: ホームに戻るたび・ページを切り替えるたびに、フェーダーが所定位置へ走り、ノブが回り、カレンダーが順に点灯します

## 権限について

| 機能 | 必要な許可 | 許可しない場合 |
|---|---|---|
| パッドの通知発光 / メディア表示 | 通知へのアクセス | 光らない・曲名が出ないだけ |
| BRT フェーダー | 設定の変更（WRITE_SETTINGS） | タップすると許可画面が開きます |

どちらも編集バーの「通知」、または BRT フェーダーのタップから許可画面に飛べます。

## 開発（スマホだけで進める場合）

どのブランチに push しても GitHub Actions が APK をビルドし、`latest` リリースを
差し替えます。状況は [Actions タブ](https://github.com/ytakaiclimb-cell/Free/actions)（3 分ほど）。

## 構成

```
app/src/main/java/com/mpc/launcher/
├── MainActivity.kt
├── data/
│   ├── AppRepository.kt      インストール済みアプリ
│   ├── Layout.kt             モジュール / ページのモデルと JSON
│   └── LayoutStore.kt        保存と初期レイアウト
├── service/
│   ├── NotificationBridge.kt 通知アクセス
│   └── LiveState.kt          通知中パッケージ / 再生中の曲
├── system/
│   ├── Media.kt              メディアセッション
│   ├── Volume.kt             音量
│   ├── Brightness.kt         明るさ
│   └── SystemScreens.kt      各種設定画面
└── ui/
    ├── Skin.kt               配色
    ├── LauncherState.kt      状態
    ├── LauncherScreen.kt     ページ / ドロワー / 編集バー
    ├── PageCanvas.kt         グリッドとドラッグ配置
    ├── Sheets.kt             ドロワー・フォルダ・アプリ選択
    └── modules/              パッド / ノブ / フェーダー / 各パネル
```
