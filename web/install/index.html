ブラウザで使う

スマホに入れる

A4 で作った POP を、インスタの投稿サイズ（1:1 / 4:5 / 9:16）に切り出すアプリです。
Google Play には出していないので、下のファイルから直接インストールします。

pop.apk をダウンロード

このリンクは常に最新版を指します

配る相手には、このコードを読んでもらってください。
スマホのカメラを向けるだけでこのページが開きます。

入れかた

  1. 上のボタンをタップしてダウンロード
  2. 通知（またはブラウザのダウンロード一覧）からファイルを開く
  3. 「提供元不明のアプリ」の許可を求められたら許可する
    「この端末に、このブラウザから入れてよい」という意味の確認です
  4. 「インストール」をタップ

知っておくこと

更新するとき同じリンクから落として上書きするだけです。アンインストールは要りません
権限求めません。写真の選択と、自分が保存した画像しか触りません
通信しません。変換はすべて端末の中で終わります
対応Android 10 以降
iPhone / PCアプリはありません。ブラウザ版が同じことをします
